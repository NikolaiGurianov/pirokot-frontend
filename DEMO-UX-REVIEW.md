# Проверка десктопного демо — 5 сентября 2026

Аудит исходников по storefront-best-practices (Medusa) и Web Interface Guidelines
(Vercel). Это не визуальный тест в браузере. Мобильная версия и публикация
документов отложены пользователем.

## Исправлено

- Заголовок страницы информации вынесен в полную ширину сетки; добавлен перенос
  длинного текста и min-width: 0. Горизонтальный overflow не маскируется обрезкой.
- Кабинет и корзина используют одинаковый outline-вариант и цвета.
- Инструкция открывается доступной кнопкой с иконкой в диалоге. Используется
  существующий Dialog с управлением фокусом, закрытием и прокруткой содержимого.
- Предусмотрено изображение инструкции через imageUrl; до его появления —
  понятное пустое состояние.

## Приоритеты

- components/site-header.tsx:24 — показать количество товаров на корзине,
  обновлять после изменения корзины; озвучивать изменение через aria-live.
- app/products/catalog-view.tsx:36 — фильтры и страница находятся только в
  React state. Синхронизировать с URL, чтобы работали обновление страницы и «Назад».
- app/products/catalog-view.tsx:76 — запросы поиска не отменяются:
  старый ответ способен заменить более свежий. Добавить отмену и задержку ввода.
- app/cart/page.tsx:103 — тарифы 500 ₽ и 3000 ₽ продублированы на фронтенде.
  Получать расчёт доставки с сервера, чтобы отображаемая сумма совпадала с заказом.
- app/products/catalog-view.tsx:27 — изображения без width/height:
  задать размеры и проверить сохранение пропорций.
- app/products/[id]/page.tsx:6 — при недоступном API возможна подстановка
  демонстрационного товара. Перед реальным запуском отделить демо-режим
  от рабочего режима и показывать ошибку загрузки.
